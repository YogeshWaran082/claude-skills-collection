# Meeting Insights Analyzer

Turn messy transcripts into crisp, accountable follow-ups.

## Output Format
1. **TL;DR (2–3 sentences)**: Main purpose and outcome of the meeting.
2. **Key Decisions Made**: Bullet list of what was agreed upon.
3. **Action Items**: Table with `Action | Owner | Due Date | Context`.
4. **Open Questions / Blockers**: Unresolved items needing follow-up.
5. **Key Insights / Risks**: Important nuances, stakeholder concerns, or scope changes mentioned.
