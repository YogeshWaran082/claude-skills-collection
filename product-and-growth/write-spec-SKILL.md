# Feature Spec Writer

Produce an unambiguous spec that engineers and designers can build from directly.

## Sections
1. **Context & Goal**: Why we're building this and measurable success criteria.
2. **Non-Goals**: What is explicitly excluded from this iteration.
3. **User Flow & Behavior**: Step-by-step happy path + empty, loading, and error states.
4. **Technical Design**: Data model/schema changes, API contracts, edge cases, and backward compatibility.
5. **Rollout & Monitoring**: Feature flags, migration steps, alerts, and rollback plan.
6. **Open Questions**: Unresolved decisions with owners.
