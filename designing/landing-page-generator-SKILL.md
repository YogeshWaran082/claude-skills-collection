# Landing Page Generator

Build responsive, conversion-focused landing pages from a product brief.

## Page Structure
1. **Hero Section**: Clear value proposition (H1), 1-sentence subheadline, primary CTA, secondary CTA, and product visual/mockup.
2. **Social Proof**: Customer logos, metrics, or testimonial strip.
3. **Problem → Solution**: 3 core pain points mapped to product capabilities.
4. **Feature Highlights**: Alternating visual + benefit blocks with scannable bullets.
5. **Pricing / Plans** (if applicable): 2–3 clear tiers with highlighted recommended plan.
6. **FAQ & Final CTA**: Top 4–5 objections answered + repeated primary CTA.

## Standards
- Mobile-first responsive layout, semantic HTML, accessible contrast, and fast-loading assets.
- Keep copy specific and outcome-oriented; avoid generic filler.
