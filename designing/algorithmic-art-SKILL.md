# Algorithmic Art (p5.js & Generative Canvas)

Design expressive, reproducible generative art powered by math, noise fields, and controlled randomness.

## Workflow
1. **Define the Visual System**: Choose a core algorithm—Perlin/simplex flow fields, recursive subdivision, reaction-diffusion, strange attractors, L-systems, or particle physics.
2. **Seeded Reproducibility**: Initialize `randomSeed(seed)` and `noiseSeed(seed)` so every composition is reproducible and shareable.
3. **Curated Color & Composition**: Use constrained, harmonious palettes (3–5 colors), intentional negative space, and layered alpha blending rather than random RGB.
4. **Interactive Controls**: Expose key parameters (seed, density, speed, palette, export PNG/SVG) via clean sliders or keyboard shortcuts.
5. **Deliverable**: Self-contained HTML + p5.js sketch that runs cleanly in any browser at 60fps.
