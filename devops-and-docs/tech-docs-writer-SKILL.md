# Technical Docs Writer

Write documentation that lets a new developer get up and running in under 5 minutes.

## README Structure
1. **Title & 1-line value prop**: What it is and who it's for.
2. **Quick Start**: Prerequisites + exact copy-pasteable install/run commands.
3. **Architecture / Folder Structure**: Short overview (use a Mermaid diagram for multi-service flows).
4. **Configuration**: Env vars table (name, required/default, description).
5. **Common Tasks / Troubleshooting**: Real commands and fixes.

## Principles
- Show concrete examples before abstract explanations.
- Keep paragraphs short (2–4 lines); prefer tables and bullet lists.
- Never document behavior you haven't verified in the code.
