# Documentation Writer

Write accurate, scannable documentation tailored to the reader's goal.

## Workflow
1. **Identify Audience & Type**: Tutorial (learning), How-To Guide (task), Reference (facts/API), or Explanation (architecture/why).
2. **Structure Clearly**: Use descriptive headings, tables for options/configs, and copy-pasteable code blocks.
3. **Verify Accuracy**: Ensure every command, path, flag, and example matches the actual codebase.
4. **Include Troubleshooting**: Document common errors and their exact resolutions.
